# Privacy Policy

Bazable stores API credentials, access tokens, and contract data **locally** on your machine in `~/.bazable/`.

When you use Bazable Cloud (optional):
- Authentication occurs via device‑code flow with Supabase (GitHub OAuth or email magic link).
- Contract data is stored in a Supabase database.

No personal data is collected by the Bazable CLI itself.  
Third‑party services (Supabase, OpenAI/Groq) have their own privacy policies.
